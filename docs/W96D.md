# W96D BLE Integration

## Ownership

HOME:

router -> BLE -> W96D

SCHOOL:

23:00-06:00

night_node -> BLE -> W96D

06:00-23:00

router -> BLE -> W96D

OUTDOOR:

phone -> BluetoothGatt -> W96D

## Rule

No automatic BLE competition or discovery takeover is performed.
The environment selects the BLE owner.

## API model

Common fields:

- power
- speed (0-100)
- natural
- turbo
- light
- battery
- vbus
- motor
